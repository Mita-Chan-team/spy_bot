# 🕵️‍♂️ Spy Business Bot v2

Улучшенная версия бота с архивом, сохранением одноразовых медиа и уведомлениями в личку.

## Что нового в v2

- **Полный архив всей переписки** (SQLite) — сохраняется каждое сообщение с момента подключения бота
- **Сохранение одноразовых фото/видео/кружков** — файлы скачиваются и приходят тебе в личку
- Уведомления о **редактировании** и **удалении** приходят **в личные сообщения с ботом**
- Удобные команды архива:
  - `.archive` — последние сообщения
  - `.archive chats` — список всех чатов
  - `.archive <chat_id> 50` — история конкретного чата
- Медиа сохраняются в папку `data/media/`

## Установка

```bash
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # Linux/macOS

pip install --upgrade pip
pip install -r requirements.txt
```

Создай файл `.env`:

```env
BOT_TOKEN=твой_токен
ADMIN_ID=твой_telegram_id
```

Запуск:

```bash
python main.py
```

## Важно

1. В @BotFather включи **Secretary Mode** для бота
2. Подключи бота в **Настройки → Telegram для бизнеса → Чат-боты**
3. Все spy-уведомления и сохранённые медиа будут приходить **тебе в личку с ботом**

## Команды

- `.help` — полный список
- `.archive 20` — последние 20 сообщений из архива

- `.fuck`, `.love`, `.gay`, `.secret`, `.type`, `.podkat`
